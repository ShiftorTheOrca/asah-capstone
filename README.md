## Segmentasi Pelanggan Berdasarkan Perilaku Pembelian menggunakan Metode RFM dan Clustering


Proyek ini adalah hasil pengerjaan capstone untuk segmentasi pelanggan untuk mendapatkan strategi marketing terbaik untuk setiap segmen. Segmentasi pelanggan dilakukan
menggunakan metode RFM dengan algoritma clustering HDBSCAN. Dataset yang digunakan berasal dari [Online Retail Dataset milik UCI](https://archive.ics.uci.edu/dataset/352/online+retail). 

## Penggunaan Produk

1. Clone repository ini ke repostory lokal Anda. 
2. Download dan install library yang dibutuhkan oleh program yang terdaftar requirements.txt. 
3. Buka terminal pada komputer Anda, dan navigasi ke folder repository lokal Anda.
4. Jalankan program dengan command `streamlit run app.py`. Device akan menjalankan aplikasi web untuk menampilkan informasi hasil clustering yang telah dilakukan. 
5. Buka browser Anda, dan masukkan alamat `localhost:8501` untuk mengakses server web yang dijalankan. 
6. Gunakan keybind `Ctrl + C` pada terminal yang sama untuk memberhentikan server.
